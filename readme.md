ELAN TEXT AI — Smart Language Analysis System
Интеллектуальная система автоматического лингвистического анализа, верификации и стилистической обработки текстов на казахском языке. Платформа специализируется на официальной документации, технических отчетах, нормативных правовых актах и деловой переписке с учетом морфологических особенностей казахского языка и стандартов терминологии.
🎯 Назначение и решаемые задачи
При подготовке документов на казахском языке часто возникают проблемы:
 * Прямые заимствования без перевода (варваризмы из русского и английского языков);
 * Ошибочный выбор отраслевого термина (кальки вместо утвержденных терминов);
 * Нарушение закона сингармонизма и правил присоединения падежных окончаний;
 * Тавтологии и нерегламентированный разговорный стиль в официальных письмах.
ELAN TEXT AI решает эти задачи через сквозной семантико-морфологический конвейер, предлагая контекстно-зависимые эквиваленты с объяснением уместности каждого варианта.
🚀 Архитектурные возможности
1. Единый дашборд с 9 оперативными счетчиками
Система классифицирует ошибки по 9 категориям со счетчиками в реальном времени:
 * Қазақша емле қателері (Орфография): нарушение гармонии гласных, опечатки, пропуск букв в заимствованных корнях (инсталяция \rightarrow орнату/инсталляция).
 * Грамматикалық қателер (Грамматика): согласование падежных (септік), множественных (көптік) и притяжательных (тәуелдік) окончаний (стандарқа \rightarrow стандартқа).
 * Тыныс белгілері (Пунктуация): обособление вводных слов (қыстырма сөздер), однородных членов и сложных синтаксических конструкций.
 * Орысша сөздер (Русские заимствования): непереведенные лексемы делопроизводства (согласование \rightarrow келісу/үйлестіру).
 * Ағылшынша сөздер (Англоязычные термины): IT и техническая терминология (control system \rightarrow басқару жүйесі).
 * Қазақша баламалар (Контекстные альтернативы): подбор 2–3 утвержденных вариантов с отраслевым комментарием.
 * Қайталанған сөздер (Тавтология): устранение необоснованного повторения смежных слов (қалды қалды).
 * Стильдік қателер (Канцелярский стиль): замена разговорных конструкций на нормативы делопроизводства (жасау керек \rightarrow әзірлеу қажет).
 * Барлық анықталған қателер (Сводная сводка): полный реестр инцидентов.
2. Подбор контекстно-зависимых казахских альтернатив
Для каждого заимствованного термина система формирует выборку с пояснением:
| Исходный термин | Рекомендуемый перевод | Альтернативы с контекстом применения |
|---|---|---|
| Разработка | Әзірлеу | 1. Әзірлеу — создание ПО, алгоритмов, цифровых продуктов.
2. Жобалау — архитектурные, конструкторские и схемные решения.
3. Дайындау — оформление регламентов, смет и договоров. |
| Control system | Басқару жүйесі | 1. Басқару жүйесі — автоматизированные процессы, менеджмент.
2. Бақылау жүйесі — мониторинг, аудит, проверка целостности.
3. Қадағалау жүйесі — надзор в сфере безопасности и комплаенса. |
3. Централизованная база дефектов (Single Source of Truth)
Каждая запись в общем хранилище нормализуется по структуре:
 * id: уникальный ключ инцидента (#ERR-001);
 * category: системная категория дефекта;
 * originalWord: оригинальный фрагмент из текста;
 * suggestedCorrection: эталонный вариант исправления;
 * kazakhAlternatives: массив объектов { word, usageContext };
 * sentenceContext: полное предложение с выделенным словом;
 * explanation: академическое грамматическое/морфологическое обоснование;
 * pageNumber: ориентировочная страница документа (из расчета ~250 слов/стр.);
 * occurrencesCount: частотность вхождения в документе;
 * status: жизненный цикл записи (pending | accepted | rejected).
4. Двухуровневый аналитический движок (Dual-Layer Engine)
 * Нейросетевой уровень (Gemini AI API): обращается к LLM с принудительной валидацией по JSON-схеме, учитывая исключения для имен собственных (Серік Ахметов), аббревиатур (IT, ҚР) и названий юрлиц.
 * Детерминированный морфологический fallback: встроенный движок регулярных выражений и словарей терминологической комиссии, гарантирующий 100% автономность работы без внешнего подключения к API.
🛠 Стек технологий
 * Разметка и логика: HTML5, Modern ES6+ JavaScript (SPA-архитектура).
 * Стилизация: Tailwind CSS (CDN runtime), кастомные темы elan-dark и elan-cyan.
 * Типографика: Google Fonts (Plus Jakarta Sans, Inter, JetBrains Mono).
 * Иконки: Lucide Icons.
 * Обработка файлов: Mammoth.js (клиентский парсинг .docx в сырой текст) + FileReader API для .txt.

⚡️ Быстрый старт
Вариант 1. Локальный запуск без зависимостей
Файл является самодостаточным. Достаточно открыть его в браузере:
# macOS / Linux
open index.html

# Windows
start index.html

Вариант 2. Запуск через локальный HTTP-сервер (рекомендуется для избежания CORS при загрузке файлов)
# С помощью Node.js:
npx serve .

# С помощью Python 3:
python3 -m http.server 8080

После запуска перейти по адресу: http://localhost:8080.
📖 Сценарии использования
 * Ввод текста:
   * Вставьте текст в область редактирования через буфер обмена;
   * Нажмите кнопку «Үлгі мәтін жүктеу» для проверки возможностей системы на подготовленном образце;
   * Либо используйте кнопку «Файл жүктеу (.docx, .txt)» для анализа локальных документов.
 * Запуск анализа:
   * Нажмите «Мәтінді талдау». Верхняя панель обновит метрики (слова, символы, объем в страницах и общий индекс качества текста).
 * Навигация по ошибкам:
   * Выберите карточку категории на дашборде для фильтрации списка в правом блоке;
   * Кликните по интересующей карточке ошибки для открытия модального окна детального разбора.
 * Принятие решений:
   * Қабылдау (Accept): применение исправления к текущему фрагменту;
   * Барлығын ауыстыру (Replace All): пакетная замена всех вхождений слова по всему тексту;
   * Қабылдамау (Reject): отклонение рекомендации и сохранение оригинала;
   * Выбор альтернативы: клик по кнопке «Таңдау» в списке вариантов переопределяет целевое слово перед применением.
 * Экспорт:
   * Нажмите «Экспорт» на верхней панели для копирования очищенного текста или выгрузки в файл.
🔒 Безопасность и конфиденциальность данных
 * Анализ выполняется внутри браузера пользователя.
 * При использовании автономного движка (Fallback) документ не покидает пределы клиентского окружения.
 * Личные имена, бренды, организационно-правовые формы и международные сокращения защищены от ложных срабатываний и принудительного перевода.
